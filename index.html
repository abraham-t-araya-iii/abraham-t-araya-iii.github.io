WEEK 7–8 · LESSON 01

Singly Linked List (Student IDs)

ONE-WAY CONNECTION

What is a singly linked list?

A singly linked list stores data in separate nodes. Every node has a value and a link called next that points to the next node. The last node points to NULL.

  • Accept five student IDs.
  • Display all IDs in the list.
  • Search for one student ID.
  • Delete a selected ID and display the updated list.

C++ sample — display only

#include <iostream>
#include <string>
using namespace std;

struct Node {
    string studentID;
    Node* next;
    Node(string id) : studentID(id), next(nullptr) {}
};

void display(Node* head) {
    for (Node* current = head; current != nullptr; current = current->next)
        cout << current->studentID << " ";
    cout << endl;
}

bool search(Node* head, const string& id) {
    for (Node* current = head; current != nullptr; current = current->next)
        if (current->studentID == id) return true;
    return false;
}

void deleteID(Node*& head, const string& id) {
    Node* current = head;
    Node* previous = nullptr;
    while (current != nullptr && current->studentID != id) {
        previous = current;
        current = current->next;
    }
    if (current == nullptr) return; // ID not found
    if (previous == nullptr) head = head->next;
    else previous->next = current->next;
    delete current;
}

WEEK 9 · LESSON 02

Doubly Linked List

TWO-WAY CONNECTION

What makes it “doubly” linked?

Each node has three parts: prev points to the previous node, data stores the value, and next points to the next node. Because of prev, we can traverse the list in both directions.

Use the values 10, 20, 30, 40, 50. Search 30, update 20 to 25, delete 40, then show the final list.

The double arrow shows that the list can move forward or backward.

C++ sample — display only

#include <iostream>
using namespace std;

struct Node {
    int data;
    Node *prev, *next;
    Node(int value) : data(value), prev(nullptr), next(nullptr) {}
};

void displayForward(Node* head) {
    for (Node* p = head; p != nullptr; p = p->next)
        cout << p->data << " ";
    cout << endl;
}

void displayBackward(Node* tail) {
    for (Node* p = tail; p != nullptr; p = p->prev)
        cout << p->data << " ";
    cout << endl;
}

bool update(Node* head, int oldValue, int newValue) {
    for (Node* p = head; p != nullptr; p = p->next)
        if (p->data == oldValue) { p->data = newValue; return true; }
    return false;
}

void remove(Node*& head, Node*& tail, Node* p) {
    if (p->prev) p->prev->next = p->next; else head = p->next;
    if (p->next) p->next->prev = p->prev; else tail = p->prev;
    delete p;
}

WEEK 10–11 · LESSON 03

Queue Data Structures

FIFO ORGANIZATION

What is a queue?

A queue follows FIFO: First In, First Out. The first item added at the REAR is the first item removed from the FRONT.

Common operations are Enqueue (add), Dequeue (remove), Peek (view front), and Display.

Three queue types

Linear

Items move in one line. A filled rear can cause a full state.

Circular

The rear wraps to the start, so freed spaces can be reused.

Priority

Removal is based on priority, not only arrival time.

Quick guide questions

What happens when a full queue receives an enqueue?

It causes an overflow; no new item can be added.

What happens when dequeue is used on an empty queue?

It causes an underflow; there is nothing to remove.

Why use a circular queue?

It reuses spaces at the beginning after items are removed.

How does a priority queue remove items?

It removes by priority: smallest first in min-priority or largest first in max-priority.

C++ sample — display only

#include <iostream>
#include <queue>
#include <vector>
#include <functional>
using namespace std;

const int MAX = 5;

class CircularQueue {
    int data[MAX], frontIndex = 0, rearIndex = -1, count = 0;
public:
    bool enqueue(int value) {
        if (count == MAX) return false; // full
        rearIndex = (rearIndex + 1) % MAX;
        data[rearIndex] = value; count++; return true;
    }
    bool dequeue(int& removed) {
        if (count == 0) return false; // empty
        removed = data[frontIndex];
        frontIndex = (frontIndex + 1) % MAX;
        count--; return true;
    }
    void display() const {
        for (int i = 0; i < count; i++)
            cout << data[(frontIndex + i) % MAX] << " ";
        cout << endl;
    }
};

int main() {
    int choice;
    cout << "1 Linear  2 Circular  3 Priority  4 Exit\n";
    cin >> choice;
    int values[] = {50, 10, 40, 20, 30};

    if (choice == 1) { // Linear queue: FIFO
        queue<int> linear;
        for (int value : values) linear.push(value); // enqueue
        cout << "Front: " << linear.front() << "\nDisplay: ";
        while (!linear.empty()) { cout << linear.front() << " "; linear.pop(); }
    } else if (choice == 2) { // Circular queue
        CircularQueue circular;
        for (int value : values) circular.enqueue(value);
        cout << "Circular display: "; circular.display();
    } else if (choice == 3) { // Priority queue
        priority_queue<int, vector<int>, greater<int>> minQueue;
        priority_queue<int> maxQueue;
        for (int value : values) { minQueue.push(value); maxQueue.push(value); }
        cout << "Min: ";
        while (!minQueue.empty()) { cout << minQueue.top() << " "; minQueue.pop(); }
        cout << "\nMax: ";
        while (!maxQueue.empty()) { cout << maxQueue.top() << " "; maxQueue.pop(); }
    }
}
